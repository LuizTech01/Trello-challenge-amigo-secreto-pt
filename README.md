# Trello-challenge-amigo-secreto-pt

## Amigo Secreto - Trello Challenge

Este projeto foi desenvolvido como parte do desafio proposto pela Oracle ONE em parceria com a Alura. A proposta era criar uma aplicação simples para organizar um amigo secreto de forma justa e divertida.

## Descrição

O objetivo da aplicação é permitir que usuários adicionem participantes, realizem o sorteio do amigo secreto e visualizem os resultados individualmente.
Funcionalidades

## Funcionalidades

    Adicionar nomes: Os usuários escreverão o nome de um amigo em um campo de texto e o adicionarão a uma lista visível ao clicar em "Adicionar".

    Validar entrada: Se o campo de texto estiver vazio, o programa exibirá um alerta solicitando um nome válido.

    Visualizar a lista: Os nomes inseridos aparecerão em uma lista abaixo do campo de entrada.

    Sorteio aleatório: Ao clicar no botão "Sortear Amigo", um nome da lista será selecionado aleatoriamente e exibido na página.
